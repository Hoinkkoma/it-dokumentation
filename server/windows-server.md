# Windows Server Rollen – Überblick

Windows Server bietet Rollen, die bestimmte Aufgaben im Netzwerk übernehmen.
Wichtige Rollen sind: Active Directory Domain Services (AD DS) für Benutzer- und Computerverwaltung,
DNS-Server für Namensauflösung, DHCP-Server zur automatischen IP-Vergabe und
Datei- und Speicherdienste für zentrale Freigaben.
Webserver (IIS) hostet Websites und Webanwendungen; Remote Desktop Services ermöglichen Terminalserver-Szenarien.
Print and Document Services verwalten Drucker im Netzwerk.
Rollen werden über den Server-Manager oder PowerShell installiert und verwaltet.
Eine saubere Trennung der Rollen über mehrere Server erhöht Sicherheit und Verfügbarkeit.
