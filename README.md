# IT-Dokumentation

Dieses Repository enthält interne Dokumentationen der Kernel Panic Consulting GmbH.
Ziel: Änderungen nachvollziehbar machen, Zusammenarbeit verbessern, Wissen zentralisieren.

## Struktur
- `netzwerk/` – IP-Konzepte, Routing, Firewall-Grundlagen
- `server/` – Windows- und Linux-Server, Rollen, Betrieb

## Arbeiten mit Git (Kurz)
- Änderungen sammeln: `git add .`
- Commit: `git commit -m "Nachricht"`
- Push: `git push`
- Branch erstellen: `git checkout -b feature-name`
- Pull Request in GitHub erstellen und mergen

## Sichtbarkeit
Wir nutzen **Private**, da interne IT-Informationen (IP-Konzepte, Serverrollen) geschützt werden müssen.
